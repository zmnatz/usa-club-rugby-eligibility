# Caution warns before an upper-side match ends a player's eligibility

The verdict only says where a player stands today, but one more match for an upper side can end their eligibility for a lower side for the rest of the season. Caution warns of that on a player who is eligible for the lower side. It never changes a verdict, so Figure 1 is unaffected, and these players count as eligible.

A player is in Caution in either case:

- **One short of the limit on any upper side** (Reg 3.5(d)(i)). The next match there forfeits the side, whatever fixtures remain.
- **Level with the upper sides' total, with no fixtures left at or below this side** (Reg 3.5(d)(ii)). A level player with fixtures left can catch up, so isn't flagged. When the remaining fixtures aren't known, as when the fixture list hasn't loaded, a tie isn't flagged either, because unknown isn't the same as none left.

Like On Track, Caution is experimental: fixture lists and the Match Record can be incomplete. Wherever it appears the report tells users to check the official Rugby Xplorer record for matches not counted here. An ineligible player gets reasons and no Caution.
